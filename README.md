# 🌍 AI Language Translator

An AI-powered English to French translator built using Flask and Hugging Face Transformers.

## Technologies
- Python
- Flask
- Hugging Face Transformers
- HTML
- CSS

## Run
```bash
pip install -r requirements.txt
python app.py
```

Open: http://127.0.0.1:5000

## Model
Helsinki-NLP/opus-mt-en-fr
